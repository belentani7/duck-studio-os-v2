# Estudo visual do Duck

## O que foi unificado

- Base escura com verde neon contido.
- Painéis translúcidos e bordas finas.
- Rótulos curtos e ação direta.
- Ferramentas reais em vez de simulação visual.
- Canal do cliente separado do painel interno.

## Leituras usadas

- `duck-studio-delivery`
- `duck-ecosystem`
- `duck-ecosystem-inspect`
- `noiacore-art-lab`

## Decisão de design

O pacote final precisa parecer um sistema de trabalho, não uma página promocional.
A hierarquia foi montada para abrir rápido:

1. identidade
2. ferramentas
3. canal de clientes
4. mapa de arquivos

## Objetivo

Entregar um Duck visualmente mais maduro, com foco real em uso, revisão e continuidade de produção.
